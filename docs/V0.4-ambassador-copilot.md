# V0.4 — Ambassador copilot (audit, plan, report)

Goal: an ambassador who signs up today can start selling Studio ATS tonight —
*who to contact, what to say, what to show, how the commission comes back.*

Guiding question for every decision: **does it help the ambassador find,
convince or convert a client more easily?**

---

## 2. Gap analysis → decisions

| Brief | Decision |
| --- | --- |
| Starter kit "Understand Studio" | new content kind `pitch` (15 s / 30 s / 2 min, problem, for whom, what the client really buys, what it is NOT). Positioning: *Studio becomes the client's digital team and infrastructure.* |
| Personal tools | one "My kit" card: link + ambassador code + QR + promo codes, everywhere the ambassador starts |
| Link and code → same `affiliate_id` | at checkout, a typed ambassador code (promo code **or** `affiliates.code`) attributes the sale **when no tracked attribution exists**. A tracked click keeps priority (no code hijacking). |
| Prospecting kit | new messages (Instagram DM, meeting proposal, after-interest, tones) in the existing `message` kind |
| Diagnostic questions | new kind `diagnostic` (question + what to listen for + where Studio helps) |
| Commercial assets | new kind `case_study`, seeded from the WayneWeb portfolio (screenshots copied to `public/portfolio`) — admin-editable |
| Sector search | `markets` gets optional `keywords` (synonyms) + `offer` (recommended tier); pure matcher `matchSectors()`; the sector sheet gathers pitch, pains, questions, projects, objections, messages, follow-ups, offer, page. Six new sectors: hospitality, restaurants, coaches, e-commerce, industry, liberal professions. No code per sector. |
| Objections | 3 new items in the existing `objection` kind (short, long, next step, linked proof via tags) |
| Follow-ups | new kind `sequence` (J+1 / J+3 / J+7 / J+14 / J+30), computed on the **existing CRM** (`stageChangedAt`), "Mark as sent" plans the next step in the prospect's `nextAction` fields — no parallel system |
| UX "What do you want to do?" | Sales Center home becomes a 7-intent hub + sector search; the full toolbox stays one tap below |
| Onboarding | 6 steps: understand → sector → what to say → link & code → first message → first prospect; finish screen explains how the commission comes back |
| Extensible / admin | everything new is `sales_content` rows or `markets` JSON → Admin → Sales content / Markets, versioned, per locale |

## 3. Architecture

- **Migration** `20261003000001_ambassador_copilot.sql`: extends the `sales_content.kind` check (`pitch`, `case_study`, `diagnostic`, `sequence`). No new table.
- **Content model** `src/lib/sales/content.ts`: body shapes + Zod field descriptors for the 4 kinds (the admin editor and validation follow automatically).
- **Pure, tested logic**: `src/lib/sales/sectors.ts` (`matchSectors`, `caseStudiesFor`), `src/lib/sales/follow-up.ts` (`followUpStatus`), `src/lib/services/ambassador-code.ts` + `src/lib/attribution.ts` (`preferTracked`).
- **Seed**: `src/content/sales-center/copilot.ts` (pitch, diagnostic, sequence, messages, objections) and `src/content/sales-center/case-studies.ts`; `npm run db:seed:generate`.
- **UI**: `/dashboard/sales-center` (hub), `/sales-center/sector?q=` (resolver), `/sales-center/targets/[target]` (sector sheet), `/sales-center/pitch`, `/sales-center/assets` (case studies + assets), `/sales-center/follow-ups`.

## 4. Report (implemented 2026-10-01, not committed, not deployed)

**Kept as is**: auth, links / cookies / `resolve_attribution`, SQL commission engine, ledger, 25% + 5% rates, payouts, referrals, dossiers, CRM, messaging, sales pages, all V0.3 content.

**Modified**
- `/dashboard/sales-center` → copilot hub: "What do you want to do?" (7 intents + "Understand Studio"), sector search, ambassador kit (link + code + QR), search; the V0.3 toolbox is folded below.
- `/sales-center/targets/[target]` → full sector sheet (angle + 15 s pitch, problems, questions, projects to show, recommended offer, page, objections with long answer + next step, messages, follow-up sequence).
- `/sales-center/assets` → projects & demos filterable by sector, then the other assets.
- Onboarding (`/dashboard/welcome`): 6 steps, shows link + code, finish screen explains how the commission comes back (pending → available → paid).
- Navigation: Sell = Copilot, Prospects, My link & code, Promo codes, Documents. Mobile tabs: Home, Copilot, Prospects, Commissions. Sales kit / Product / Find / Campaigns stay reachable from the copilot.
- `/dashboard/link` shows the ambassador code.
- Checkout + `/buy`: the code field accepts a promo code **or** the ambassador code; it attributes the sale (`attribution_source = manual`) only when no tracked click / private page exists. A tracked attribution always wins; a promo code of another ambassador stays invalid (unchanged).
- **Bug fixed**: saving a sector in Admin → Markets erased pains / needs / outcomes / discovery / avoid of that locale. The editor now edits (and keeps) them, plus `keywords` and `offer`.

**Added**
- Content kinds `pitch`, `case_study`, `diagnostic`, `sequence` (admin-editable like all `sales_content`).
- Seed: 1 pitch, 7 diagnostic questions, 2 follow-up sequences (J+1/3/7/14/30 and after the offer), 7 messages (Instagram DM, direct / warm tones, after interest, meeting, share a project, revive), 3 objections (already a CRM, I can do it myself, I don't understand), 19 case studies from the WayneWeb portfolio (screenshots in `public/portfolio`), 6 sectors (hospitality, restaurants, coaches, e-commerce, industry, liberal professions), synonyms + recommended offer on the 20 existing sectors.
- Pages `/sales-center/pitch`, `/sales-center/sector?q=`, `/sales-center/follow-ups` ("mark as sent" plans the next step in the prospect's own `nextAction` fields).

**Migration**: `20261003000001_ambassador_copilot.sql` (kind check only). Content goes through `supabase/seed.sql` (regenerated).

**Verification**: `tsc` ✓, ESLint ✓, 95 unit tests ✓ (8 new), SQL harness ✓ all suites + `ambassador_copilot_test.sql` (9 assertions). Browser (demo mode, isolated copy): hub → search "hôtel" → sector sheet → assets by sector → follow-up "mark as sent" → onboarding 6 steps → prospect created → admin sector save. Mobile 375 px: no horizontal scroll, no console error. `next build` compiled; its type-check step could not finish because the disk is full.
